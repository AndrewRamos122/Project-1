# My Duelist Journey

This is a starter template for Project 1: Personal Website. It contains:

- `index.html` — homepage
- `cards.html` — card collection
- `strategies.html` — deck and dueling strategies
- `community.html` — community page with a sample form
- `styles.css` — shared external stylesheet

## Before submitting

1. Replace the sample writing with your own experiences and opinions.
2. The `media` folder contains the supplied Black Rose Dragon image and opening-theme MP3. Give any future images useful `alt` text.
3. The requested MDN elements are demonstrated in the HTML comments: `audio`, `big`, and `marquee`. The requested attributes are `placeholder`, `autoplay`, and `loop`. The prompt lists three attributes even though it says four; ask your instructor whether another attribute is required.
4. The comments explain that `big` and `marquee` are obsolete in HTML5, while autoplay may be blocked by browsers and placeholder should not replace visible labels.
5. Validate each page and test every navigation link in Chrome. If the audio does not start automatically, click Play because Chrome may block audible autoplay.
6. The form is only visual in this HTML-only project; it does not send messages until you connect it to a server.
